Firoz Download Manager
======================

চালানোর নিয়ম (Python লাগবে: https://www.python.org/downloads/ - "Add Python to PATH" টিক দিতে হবে)
  1) run.bat এ ডাবল ক্লিক করুন  -> প্রোগ্রাম খুলবে।

.exe বানানোর নিয়ম
  1) build_exe.bat এ ডাবল ক্লিক করুন।
  2) শেষ হলে  dist\Firoz Download Manager.exe  পাবেন। (icon.ico নামে ফাইল রাখলে সেটাই আইকন হবে)

ব্রাউজার ইন্টিগ্রেশন (Chrome / Edge / Brave)
  1) ব্রাউজারে chrome://extensions খুলুন, "Developer mode" অন করুন।
  2) "Load unpacked" চাপুন, browser_extension ফোল্ডারটি সিলেক্ট করুন।
  3) প্রোগ্রাম চালু থাকলে ব্রাউজারের ডাউনলোড আপনা-আপনি Firoz Download Manager এ চলে আসবে।
     লিংকে রাইট-ক্লিক করেও "Download with Firoz Download Manager" বেছে নেওয়া যায়।

ফিচার
  - একসাথে ৮ (সেটিংসে ১-১৬) কানেকশনে দ্রুত ডাউনলোড, Pause / Resume (প্রোগ্রাম বন্ধ করলেও চলবে)
  - Queue, একসাথে কয়টা ডাউনলোড চলবে তা ঠিক করা, Speed limit
  - Clipboard এ লিংক কপি করলেই Add window খোলে, একসাথে অনেক লিংক
  - Video / Music / Compressed / Documents ইত্যাদি ফোল্ডারে অটো সাজানো
  - ডাউনলোড শেষে PC Shutdown (Windows)
